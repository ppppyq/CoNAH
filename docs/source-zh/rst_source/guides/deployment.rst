分布式与远程 RPC 部署
======================

CoNAH 采用基于标准 HTTP JSON-RPC（ ``comm_harness/rpc.py`` ）的服务化架构，支持从 **单机多进程开发** 平滑扩展到 **跨服务器多 GPU** 与 **真实多机工控机集群** 。

三种典型部署形态
------------------

1. **单机本机回环模式（默认开发与消融）**
   环境服务（ ``env_server`` ）、信道服务（ ``comm_server`` ）与 ``N`` 个机器人进程全部运行在同一台电脑上，通过 ``http://127.0.0.1:<port>`` 通信，单次调用延迟低于 ``1 ms`` 。

2. **跨服务器多 GPU 模式（仿真机 + 模型机分离）**
   将重型 3D 仿真器与视觉分割服务部署在带显卡的仿真服务器上，将信道服务或大模型网关部署在另一台主机上，机器人进程通过命令行参数 ``--env-endpoint http://<ip>:<port>`` 与 ``--comm-endpoint http://<ip>:<port>`` 直接连接，彻底消除 Python 3.8（Habitat）与 Python 3.11（现代 Agent SDK / Sionna）的环境冲突。

3. **多机真机分布式模式**
   每台小车/无人机机载工控机运行自己的 ``AgentSession`` 进程，通过本机 RPC 控制底盘、相机与机载 **USRP** 电台驱动，机间通信完全通过空气中的真实无线电波完成。
