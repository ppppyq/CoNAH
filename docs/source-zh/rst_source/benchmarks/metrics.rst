评测指标体系
=============

CoNAH 将 **任务完成效果** 、 **无线通信代价** 与 **智能体执行合规性** 统一纳入评测闭环，且严格保证所有特权真值（目标真实坐标、测地距离）只留在环境服务端评测钩子中，绝不泄露给任何智能体策略。

1. 多机任务评测指标
---------------------

- **Team SR（团队成功率）** ：本场任务的所有目标中，成功被任一机器人到达并验证通过的目标占比（ ``[0.0, 1.0]`` ）。
- **Team Oracle SR（团队近距达标率）** ：在轨迹历史中，任一机器人曾经靠近到目标阈值半径内的目标占比（用于区分“路过未识别”与“从未找到区域”）。
- **Team SPL（路径效率加权成功率）** ：综合考虑团队成功目标数与路径长度效率的加权指标。

2. 通信效率与信道鲁棒性指标
-----------------------------

- **Source Bytes / Delivered Bytes（通信字节开销）** ：由 ``Envelope.serialized_bytes`` 逐包精确累加，衡量完成一次多机协同任务消耗的真实无线载荷。
- **Packet Delivery Ratio (PDR)** ：成功送达接收端的链路数占总发包链路尝试数的比例，同时按丢包原因细分统计（ ``mtu_exceeded`` 、 ``bandwidth_exceeded`` 、 ``out_of_range`` 、 ``packet_loss`` 、 ``channel_blackout`` ）。
- **Bytes-per-Success** ：每成功完成 1 个协同目标平均消耗的跨机字节数，用于评估不同记忆压缩与协同协议的带宽效率。

3. Harness 运行合规审计指标
-----------------------------

- **Harness Violations（违规次数）** ：由 ``HarnessRuntime`` 实时审计工具调用闭合性、观测新鲜度与动作回执连续性；健康运行应始终保持 ``violations == 0`` 。
- **Receipts（可验证回执数）** ：每台机器人物理动作（ ``WORLD_MUTATING`` ）与无线发包（ ``NETWORK_TX`` ）生成的不可伪造回执总数。
